Thank you for checking out globeview!
Globeview is my app that allows users to highlight countries they've visited, attach pictures and notes, along with drawing travel routes between locations. 
Furthermore, globe view also has a built in "Journey" mode, which plays out all countries visted in accordance to chronological order and neatly displays attached pictures and information. 
The app is privacy focused, and this was also my number 1 goal when creating the app. 
I'm sure there are superior versions of this same product out there, however I wanted one that did not sell data or use private information in a malicious manner. 
Finally, this is a hobby project of mine, I'm currently developing it as a side project along side other things. 
Feel free to try it out! And i wish you happy mapping. :)
